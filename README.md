# Living Life Home Connections Website

React + Vite website for Living Life Home Connections LLC.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this GitHub repository into Vercel and click **Deploy**.

## Replacing images

The website currently has styled image placeholders. Put your photos inside the `public` folder, then replace the placeholder sections in `src/App.jsx` with `<img src="/your-image-name.webp" />`.
